Privacy policy

Last updated 31 October 2026

Cellucid (www.cellucid.com) is a free, open-source web app for looking at single-cell data. It runs in your browser. This page says what it reads, what it keeps and what it sends.

Your data

Cellucid reads your data in your browser, from where it is: a file on your computer, a server you connect to, or a link you open (for example GitHub, Zenodo, Figshare, Google Drive or OneDrive). It reads only the parts a view needs. Your data is never uploaded to a Cellucid server.

What Cellucid reads is held in your browser tab's memory while the dataset is open. So that the same file opens faster next time, some of it is also kept in this site's own storage in your browser profile, on your computer: the parts of a remote file it downloaded (from a link, a data repository, or a private Google Drive or OneDrive file), the gene index it builds for a matrix stored cell by cell, and the converted copy of a file it has to read whole (an R object, a MatrixMarket folder, or a file whose host serves only whole files). These are kept under the file's version, only when the source names one, and none of a file's parts are kept when it is served from your own computer or a notebook. Cellucid also keeps a draft of the highlights you make on each dataset and how fast each data host answered, and, in Chrome, Edge and other Chromium-based browsers, the browser's handle of a file or folder you open from your computer (its name, size and modification time, never its path or content), kept in this browser only so that a reload or a saved session can reopen it with one click once you allow it. Remove any of it under Session › Open data › Stored › Manage…, or by clearing this site's data in your browser; a private window keeps none of it after it closes.

Google Drive and OneDrive

  • What Cellucid accesses. On Google Drive, only the files you choose for Cellucid in Google's file picker (the drive.file permission), and a file shared with anyone who has its link. On OneDrive, the files your Microsoft account can read (Files.Read, and Files.Read.All only when you open a file someone in your organisation shared with you), and only the file you open. Cellucid only reads; it never changes, creates or deletes a file.
  • Where the data goes. Your browser reads the file straight from Google or Microsoft. Neither the file nor your sign-in passes through a Cellucid server.
  • Where your sign-in lives. The access token Google or Microsoft gives Cellucid lasts about an hour. It is kept in your browser tab's session storage, which your browser may also write to its profile on disk to restore the tab; it survives a reload of the tab and is deleted when the tab closes, when you sign out, or when it expires. Microsoft's renewal token, which renews the access without a click for up to 24 hours, is kept only in the page's memory and is gone after a reload. Neither is ever saved by Cellucid anywhere else, put in a link, a saved session or a figure, or sent anywhere except back to Google or Microsoft.
  • What is kept of the file. The parts of the file Cellucid downloaded are kept in this site's storage in your browser profile under the file's version, so it opens faster next time, until you remove them (Session › Open data › Stored › Manage…) or clear this site's data.
  • What a link or a saved session records. Only which service and which file (its id), never a token, and never the key a shared link carries to grant access.
  • Revoking access. Signing out revokes the Google token at Google; Microsoft offers no way for an app like Cellucid to revoke its own token, so signing out forgets it and it lapses within the hour. To remove Cellucid's access altogether, use myaccount.google.com/permissions, account.live.com/consent/Manage or, for a work or school account, myapps.microsoft.com.

Cellucid's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Community annotation (GitHub)

If you sign in with GitHub to share annotations, sign-in and repository requests go through a small Cellucid-operated authentication service, which relays them to GitHub. Your GitHub token expires after 8 hours. It is kept in your browser tab's session storage (which your browser may write to its profile on disk to restore the tab) and is deleted when it expires, when the tab closes, or when you sign out; signing out also revokes it at GitHub. What you publish is stored in the GitHub repository you choose, under GitHub's terms. When you search for a cell type while annotating, the term or marker genes you typed are sent through the same service to the Cell Annotation Platform (celltype.info), and nothing else; typing a name or ORCID iD in your annotation profile searches ORCID's public registry (orcid.org) from your browser.

Usage statistics

On www.cellucid.com, Cellucid sends anonymous usage statistics to Google Analytics: page views of the page's address without its query, how long loading took, which features were used, a dataset's coarse shape (ranges of cell and gene counts), and the events Google's tag records on its own (page changes, scrolling, clicks on links to other sites, file downloads from links, form use), each address in them stripped of any part that names a dataset or server. Google Analytics also records, as it does on any site, the visitor's approximate location (country, region and city, worked out from the network address, which it does not keep) and the kind of browser, operating system and device. It never sends a dataset's name, contents, link, file name or a sign-in. The page tells Google not to use what it collects for advertising (no advertising storage, no advertising use of user data, no personalisation, no Google signals). Google Analytics keeps two cookies of its own in your browser (_ga and _ga_K4774ZWGEQ) to tell a returning visitor from a new one. A viewer in a Python or R notebook, a viewer a Python or R program opens in a browser tab, and a copy of Cellucid you run yourself send nothing and set no cookie.

Stored in your browser

In this site's storage in your browser profile, Cellucid keeps your preferences (such as the theme), how fast each data host answered, community-annotation drafts and the annotation files it downloaded, a draft of the highlights you made on each dataset (which cells, by their row in the file, so a reload does not lose them), in Chromium-based browsers the browser's reference to each file or folder you opened from your computer (its name and size, never its path or content, so a reload can reopen it with one click), what it kept of the files you opened (see Your data), and on www.cellucid.com (never on a copy served from your own computer) its own scripts, stylesheets and fonts, so a later visit loads them without the network; sign-ins are kept in the tab's session storage. On www.cellucid.com, Google Analytics adds its cookies. Session › Open data › Stored › Manage… lists what is kept of your data and removes what you choose; clearing this site's data in your browser removes all of it.
