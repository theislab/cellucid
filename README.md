# Cellucid

**See every cell. Query any gene. Explore in 2D and 3D.**

Cellucid is a browser-first, GPU-accelerated workspace for exploring large
single-cell datasets in real time. Move naturally through 1D, 2D, and 3D
embeddings, compare populations side by side, follow cellular dynamics, and
turn an exploratory view into a reproducible figure or shared session.

**[Explore Cellucid](https://www.cellucid.com)**

## Features

- Fast WebGL rendering with adaptive detail, up to 100 million cells in 3D on a 16 GB laptop
- Subsampled reading: open a seeded share of the cells (uniform, storage-aligned blocks, stratified, spatial), downloading only the parts of the file that hold them; the same cells in Python, R, links and sessions; a dataset too large for the device opens a share that fits
- Interactive gene-expression and cell-metadata coloring, filtering, and highlighting
- Independent multiview comparisons with per-view colors and filter stacks
- Animated RNA-velocity and drift overlays, KNN connectivity, and volumetric smoke
- Built-in marker genes and differential expression with scanpy-compatible statistics on any expression matrix of the file (X, a layer or raw), dot plots, gene signatures (module score, UCell), cell-type composition across samples and conditions, correlation and quick insights, in resizable windows
- Orbit, Planar, and Free Fly navigation with reproducible Camera Path animation
- Community annotation, voting, and consensus with optional GitHub collaboration
- Shareable session state, dataset links, "Open in Cellucid" README badges and embed snippets, plus publication-ready SVG and high-DPI PNG export
- A hover card with the values of the cell under the pointer, in every view, at no rendering cost
- Reads AnnData directly (H5AD, Zarr folders and Zarr ZIP), and Loom, 10x Cell Ranger HDF5 and `outs/` folders, MuData (`.h5mu`, MuData Zarr), Seurat and SingleCellExperiment objects (`.rds`, `.rda`, `.RData`) and MatrixMarket folders as AnnData, with a Modality choice for multimodal data, from your computer, a link (CELLxGENE, GEO, Zenodo, Figshare, Hugging Face, GitHub, Dropbox, Google Drive, OneDrive or any web address), a dataset catalog, a local or remote server, or a Jupyter notebook or R session; a private Google Drive or OneDrive file opens for a collaborator after one sign-in, with no server involved; the Python and R packages write Cellucid-ready AnnData
